# 🌿 Welcome to Plant Doctor

## 📌 Project Info

**GitHub Repo**: https://github.com/aaronsoundararajan-stack/Plant-Doctor

Plant Doctor is a smart application that helps identify plant diseases and provides suggestions for treatment and care.

---

## 🛠️ How can I run this project?

There are several ways to run this application.

### **Use Local Setup (Recommended)**

Make sure you have **Python installed**.

Follow these steps:

```sh
# Step 1: Clone the repository
git clone https://github.com/aaronsoundararajan-stack/Plant-Doctor.git

# Step 2: Navigate to the project directory
cd Plant-Doctor

# Step 3: Install required dependencies
pip install -r requirements.txt

# Step 4: Run the application
python app.py
```
